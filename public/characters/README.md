# Character portraits

Drop one image per council member here and the UI picks it up automatically.
Until a file exists, the app falls back to a rune glyph.

Filenames (lowercase, any of .png / .jpg / .webp):

  steve.png  hopper.png  dustin.png  max.png  vecna.png  eleven.png

Square images around 256x256 or larger look best. They are shown cropped in a circle.
